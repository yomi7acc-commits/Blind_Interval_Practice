# Blind Interval Practice

PC の画面の片隅に浮かべておける、音楽理論のトレーニングツールです。
問題が1つずつ出るので、答えをキーボードで入力します。音程・コード・調号など6つのモードがあります。

> A tiny, translucent always-on-top widget for music theory drills —
> intervals, chord tones, scale degrees, key signatures, transposing instruments and the circle of fifths.
> Type the answer (e.g. `eb`, `f#`) and press Enter.

## モード

設定（Esc）か右クリックメニューの「モード」で切り替えます。

| モード | 問題の例 | 答え方 |
|---|---|---|
| 音程 | `E♭` 長3度 ↑ | `g` |
| コード構成音 | `A♭m7` | `ab cb eb gb`（スペース区切り、順不同） |
| ディグリー | `Ⅵm`（キー E♭） | `c`（ルート音だけでOK。`cm` と打っても可） |
| 調号 | `♯×4` 何調？ | `e`（長調）または `c#m`（短調） |
| 調号（逆向き） | `C♯m` 調号は？ | `4#`（調号なしは `0`） |
| 移調楽器 | `D`（in B♭ 記譜 → 実音） | `c` |
| 五度圏 | `G` 5度上 | `d`（答えるまでの秒数も表示） |

## 特徴

- **目立たない透明 UI** — 使っていないときは背景が消え、縁取りした文字だけが浮かびます。マウスを乗せると背景が出ます。
- **正しい表記で判定** — C から短3度上は D♯ ではなく E♭。表記ちがい（異名同音）は黄色で教えてくれます。
- **苦手を多めに出す** — 間違えた項目（例: 増4度、m7♭5、キー G♭）ほど出やすくなります。苦手の一覧は設定画面で見られます。
- **♯・♭ を素早く入力** — 音名のキーの右隣で ♯、左隣で ♭（例: `e` → `r` で E♯、`e` → `w` で E♭）。方向キーも使えます。
- **自動送りモード** — 一定の秒数で答えを表示し、次の問題に進みます。楽器で弾く練習にも使えます。
- 答えを表示するときに、問題の音を鳴らせます（Windows のビープ音）。

## ダウンロード（かんたん）

[Releases](https://github.com/yomi7acc-commits/Blind_Interval_Practice/releases/latest) から `BlindIntervalPractice.exe` をダウンロードして、ダブルクリックするだけです。インストールも Python も不要です（Windows 10 / 11）。

- 初回は「Windows によって PC が保護されました」と出ることがあります。署名のない個人製アプリのためです。「詳細情報」→「実行」で起動できます。
- 設定は `%APPDATA%\BlindIntervalPractice` に保存されます。

## Python で動かす

Python 3.9 以上（tkinter 付き。python.org の標準インストーラーなら入っています）があれば、外部ライブラリなしで動きます。
`interval_trainer.pyw` をダブルクリックで起動します（コンソールは出ません）。

```bash
pythonw interval_trainer.pyw
```

EXE を自分で作る場合:

```bash
pip install pyinstaller pillow
build.bat
```

`dist\BlindIntervalPractice.exe` ができます。

## 操作

| 操作 | 内容 |
|---|---|
| `a`〜`g` | 音名を入力 |
| `#` / `+` / 右隣のキー / `→` `↑` | ♯（音名の後） |
| `b` / `-` / 左隣のキー / `←` `↓` | ♭（音名の後。1文字目の `b` は音名 B） |
| `x`、または ♯ を2回 | ダブル♯（♯♯） |
| `Enter` | 判定。未入力なら答えを表示、答えが出ていれば次の問題へ |
| `Space` | 次の問題（コード構成音モードでは音の区切り） |
| `Backspace` | 1文字消す |
| `Tab` | 自動送りの開始・停止 |
| `Esc` | 設定を開く・閉じる |
| ドラッグ | ウィンドウを移動 |
| 右クリック | メニュー（モード切り替え・終了もここから） |

右隣・左隣のキーは、直前に打った音名のキーが基準です。

| 音名 | ♭（左隣） | ♯（右隣） |
|---|---|---|
| A | — | S |
| B | V | N |
| C | X | V |
| D | S | F |
| E | W | R |
| F | D | G |
| G | F | H |

入力の例: `eb` / `ew` → E♭、`f#` / `fg` → F♯、`bb` → B♭、`abb` → A♭♭

判定の表示: 緑 = 正解、黄（`D♯ ≈ E♭`）= 音は合っているが表記ちがい、赤 = 不正解

## 設定

Esc か右クリックメニューから開きます。設定とウィンドウの位置は `interval_trainer.json` に保存されます（Python 版は同じフォルダー、EXE 版は `%APPDATA%\BlindIntervalPractice`）。

- モード、モードごとの出題範囲（音程の種類、コードの種類、三和音／四和音、楽器、出題の向きなど）
- ルート音・調に ♯ / ♭ を含めるか
- 苦手を多めに出す、苦手の一覧、記録のリセット
- 自動送りの秒数、答えを表示するまでの秒数
- 待機中の濃さ、待機中に背景を消すか
- 答えで音を鳴らす / 最前面に表示 / ダブル♯・ダブル♭を避ける / 異名同音も正解にする
