# Blind Interval Practice

PC の画面の片隅に浮かべておける、音程（インターバル）練習ツールです。
ランダムなルート音と音程が出るので、答えの音名をキーボードで入力します。

> A tiny, translucent always-on-top widget for practicing musical intervals.
> A random root and an interval are shown; type the answer note (e.g. `eb`, `f#`) and press Enter.

## 特徴

- **目立たない透明 UI** — 使っていないときは背景が消え、縁取りした文字だけが浮かびます。マウスを乗せると背景が出ます。
- **ルート音はランダム** — ♯・♭ を含めるかどうかを設定できます。
- **音程は指定かランダム** — 1つだけ選べばその音程を、複数選べばその中からランダムに出題します。
- **正しい表記で判定** — C から短3度上は D♯ ではなく E♭。表記ちがい（異名同音）は △ で表示します。
- **自動送りモード** — 一定の秒数で答えを表示し、次の問題に進みます。楽器で弾く練習にも使えます。
- 答えを表示するときに、ルート音と答えの音を鳴らせます（Windows のビープ音）。

## 必要なもの

- Windows 10 / 11
- Python 3.9 以上（tkinter 付き。python.org の標準インストーラーなら入っています）

外部ライブラリは不要です。

## 使い方

`interval_trainer.pyw` をダブルクリックで起動します（コンソールは出ません）。

```bash
pythonw interval_trainer.pyw
```

| 操作 | 内容 |
|---|---|
| `a`〜`g` | 音名を入力 |
| `#` / `+` | ♯　（2文字目以降） |
| `b` / `-` | ♭　（2文字目以降。1文字目の `b` は音名 B） |
| `x` | 𝄪 |
| `Enter` | 判定。未入力なら答えを表示、答えが出ていれば次の問題へ |
| `Space` | 次の問題 |
| `Backspace` | 1文字消す |
| `1` | 自動送りの開始・停止 |
| `Esc` | 設定を開く・閉じる |
| ドラッグ | ウィンドウを移動 |
| 右クリック | メニュー（終了もここから） |

入力の例: `eb` → E♭、`f#` → F♯、`bb` → B♭、`abb` → A𝄫

判定の表示: 緑 = 正解、黄（`D♯ ≈ E♭`）= 音は合っているが表記ちがい、赤 = 不正解

## 設定

Esc か右クリックメニューから開きます。設定とウィンドウの位置は、同じフォルダーの `interval_trainer.json` に保存されます。

- 出題する音程（短2度〜完全8度）
- ルート音に ♯ / ♭ を含めるか
- 方向（上行 / 下行 / ランダム）
- 自動送りの秒数、答えを表示するまでの秒数
- 待機中の濃さ、待機中に背景を消すか
- 答えで音を鳴らす / 最前面に表示 / 𝄪 𝄫 を避ける / 異名同音も正解にする
